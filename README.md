# Programming Practice: C/C++ and Python

A learning repository for small programming exercises and experiments. The files currently cover multiple standalone examples rather than one integrated application.

## Contents

- **C/C++ practice** — source files such as `avgcode.c` and related exercises.
- **Python practice** — scripts such as `avg.py` and other small examples.
- **Text and data files** — supporting files used by individual exercises.

## Getting started

1. Browse the source files and choose an exercise.
2. Read the selected file to check its inputs and expected behavior.
3. Run it with the appropriate compiler or Python interpreter.

### Python

Install Python 3, then run a selected script:

```bash
python avg.py
```

### C

With GCC installed, compile the C source before running it:

```bash
gcc avgcode.c -o avgcode
./avgcode
```

On Windows, run the resulting executable from Command Prompt or PowerShell. These commands are examples; adjust the filename and command for the exercise you choose.
